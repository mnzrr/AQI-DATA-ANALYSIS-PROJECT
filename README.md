# 🌍 AQI Index Analysis

An interactive **Air Quality Index (AQI) Analysis Dashboard** built using **Microsoft Power BI**.

## 📊 Project Overview
This project analyzes AQI data to identify air quality levels, major pollutants, city-wise AQI, and AQI trends over time.

## 🔍 Key Features
- City-wise AQI analysis
- State-wise AQI visualization
- AQI level distribution
- Pollutant occurrence frequency
- AQI trends over time
- Interactive Year, State, and City filters
- Identification of major pollutants such as PM10, SO2, O3, and PM2.5

## 🛠️ Tools Used
- **Microsoft Power BI**
- **Power Query**
- **DAX**
- **Data Visualization**

## 🎯 Objective
To transform AQI data into an interactive dashboard that makes air-quality patterns and pollutant trends easy to understand.
